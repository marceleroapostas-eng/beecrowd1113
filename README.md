# Beecrowd 1113 - Crescente e Decrescente

## Descrição
Programa desenvolvido em Java para verificar se dois números inteiros foram digitados em ordem crescente ou decrescente.

## Linguagem
Java

## Entrada
O programa recebe pares de números inteiros X e Y. A leitura termina quando os dois valores são iguais.

## Saída
Imprime "Crescente" quando X for menor que Y ou "Decrescente" quando X for maior que Y.
